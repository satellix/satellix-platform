# Satellix

### Overview

Satellix is a platform for tracking satellites and predicting when they will pass over a chosen location.

It aims to let users:

\- Explore satellites and their orbits.\
\- View upcoming satellite passes for selected locations.\
\- Subscribe to notifications about upcoming passes.\
